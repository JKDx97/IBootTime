# iPXE Boot Assets

Place the following iPXE binary files in this directory:

- `undionly.kpxe` - Legacy BIOS chainloader
- `ipxe.efi` - UEFI generic bootloader  
- `snp.efi` - UEFI SNP driver bootloader

Download from: https://boot.ipxe.org/

These files are embedded into the final binary at compile time.
